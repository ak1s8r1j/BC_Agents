# Contributing to BC Agents

Thanks for your interest in contributing! This repo collects specialized AI agent definitions for Microsoft Dynamics 365 Business Central work.

## How to contribute

1. Fork the repository.
2. Create a branch for your change.
3. Add a new agent file, or improve an existing one (fix inaccuracies, add missing detail, improve clarity).
4. Open a pull request describing what you changed and why.

All pull requests are reviewed before merging.

## Ground rules

- **Do not delete or remove existing content.** Pull requests that delete files, or remove existing sections/instructions from an agent file, will not be merged. If something looks wrong or outdated, propose a correction or addition instead of removing it — call out the concern in your PR description so it can be discussed.
- **Additive changes are welcome:** new agent definitions, expanded coverage, corrections, and clarifications.
- Keep new/edited agent files consistent in structure and tone with the existing ones in [Agents/](Agents/).
- Keep the [README.md](README.md) table up to date if you add a new agent.

## Questions

Open an issue if you're unsure whether a change fits before putting the work in.
